## ✨ Features

### 🎓 Student & Teacher Directory
- Look up a student by name or LRN to see their current section, school year, and adviser
- Look up a teacher to see every subject and section they hold
- Section history per student — every past section/school year, with the current one flagged, plus optional "Transferred from" tracking for students who came from another school
- Add, edit, and delete student and teacher records, with checkbox multi-select for bulk deletion

### 🔍 Search, Filter & Sort
- Live search by name or ID across the Students and Teachers tabs
- Browse by Section or School year dropdowns, with the active filter shown as a removable chip
- Sort the visible list Alphabetically (A–Z), by Latest added, or Earliest added — remembered per browser

### 📷 Scan-to-Add (OCR)
- Scan a printed class list or ID with your device camera or a photo
- Text recognition runs fully on-device (Tesseract OCR in the browser) — no photos are uploaded anywhere
- Review screen lets you fix, uncheck, or add rows before bulk-saving the scanned students

### ☁️ Sync & Backup
- Optional Google sign-in to sync the directory to your own Drive and pick up where you left off on another device
- "Continue as Guest" mode for local-only use, with an on-screen reminder to back up before clearing browser data
- Manual backup: download a `.json` backup file or import one to restore/transfer data
- Everything autosaves in the browser as you go — no account or server required to use the app

### 🎨 Customization
- Branding panel to upload your school's logo, edit the heading/title/description text, and choose which side the logo sits on
- Light and dark mode, togglable from the header or right on the sign-in screen, with the choice remembered per browser

### 📱 Cross-Platform
- Installable as a Progressive Web App (PWA) with offline support via a service worker
- Packaged as a standalone Windows executable and an Android APK, alongside the live web app
- Responsive layout tuned for both desktop and mobile use

## 🚀 Installation Instructions

<details>
<summary><b>💻 Windows Installation</b></summary>

1. Download **`CC316-Project-win32-x64.zip`** from the links above.
2. Extract the `.zip` file to your preferred folder or Desktop.
3. Double-click **`CC316-Project.exe`** to open and run the app.
</details>

<details>
<summary><b>📱 Android Installation</b></summary>

1. Download **`RollandRegister.apk`** directly to your phone.
2. Open the file manager on your device and tap the downloaded `.apk`.
3. If prompted by Android, grant permission to **Allow installation from unknown sources**.
4. Complete the installation and open **RollAndRegister** from your app drawer.
</details>
